## Diferencias evidentes Figma vs Ionic (evidencia)

Comparación directa de pantallas clave. Solo se listan diferencias claramente visibles en las capturas; no se infieren cambios que no se puedan ver.

1. **Configuration — estructura de secciones de sincronización distinta.** Figma (`profile/configuration-564-7663.png`) muestra **dos** bloques separados: "Subida de datos" y "Bajada de datos", cada uno con su propio botón "Sincronizar con la nube" y su propio indicador "Sin sincronizaciones pendientes". La captura Ionic (`docs/evidence/profile/screen-14-configuration.png`) tiene **una sola** sección combinada "Sincronizar mediciones" (con badge de estado y un único botón). Además, Ionic agrega un chip expandible "Permisos requeridos" bajo el toggle de notificaciones que no aparece en el frame de Figma capturado. Esto es relevante para paridad: el RN debería decidir si replica el Figma (dos secciones) o mantiene el comportamiento Ionic actual (una sección).

2. **Profile — header sin ícono de campana en Figma.** El frame `profile/profile-559-5843.png` muestra únicamente flecha de back (←) y título "Perfil" en el header; no hay ícono de notificaciones (campana) a la derecha. Tanto la nota de `docs/evidence/app-shell/README.md` (línea 51: "Flecha back izquierda + título 'Perfil' centrado + botón campana derecho") como `docs/evidence/profile/README.md` (línea 120) confirman que la implementación Ionic **sí** tiene el botón de campana con badge de no-leídos que navega a `/alerts`. Esto es una diferencia real de contenido del header, no solo de estilo.

3. **Achievements — SÍ tiene botón de volver en ambos.** Se verificó visualmente: Figma (`profile/achievements-1002-32355.png`) tiene flecha de back blanca sobre header teal + título centrado "Tus logros" + FAB "¿Dudas?"; la captura Ionic (`docs/evidence/profile/screen-09-achievement-with-data.png`) también tiene el mismo back + mismo título + mismo FAB. **No hay diferencia** en este punto — ambos coinciden. La única diferencia menor es de contenido de datos (Figma muestra 4 logros con flor 🌼 desbloqueada de más entre los primeros 8 íconos; el estado Ionic capturado con datos reales muestra 16 brotes uniformes, probablemente por diferencias en los datos de prueba, no en el diseño).

4. **Home y Login — paridad visual muy alta ya lograda.** Comparando `home/home1-530-7951.png` vs `docs/evidence/home/screen-14-home-reload-with-data.png`, y `login/login-1002-33767.png` vs `docs/evidence/auth-login/screen-01-login-vacio.png`: layout, colores, textos, tab bar y jerarquía visual son prácticamente idénticos. Única diferencia notable: Figma renderiza una barra de estado de dispositivo (hora/batería/señal) integrada en la parte superior de cada frame; las capturas Ionic (tomadas en navegador web) no incluyen esa barra de estado del SO — no es una diferencia de diseño de la app, es una limitación del método de captura Ionic.

5. **Registro de medición (RegisterMeasurementScreen) — copy y estado del botón "Guardar".** Comparando `registros/register-temp-humidity-max-571-7277.png` vs `docs/evidence/measurement/screen-04-register-form-flow1-empty.png`: el título de header en Figma dice "Registros máximos" (plural) mientras que Ionic muestra "Registro máximos" (singular) — inconsistencia de copy entre ambas fuentes que vale la pena resolver antes de fijar el texto en RN. El resto (tarjetas de Temperatura/Humedad máxima, colores por tipo de dato, ícono de flecha verde, link "¿Cómo ver este dato?") coincide.

6. **Tab bar — el componente de UI KIT no debe tomarse como referencia literal.** `ui-kit/b-bar-6503-17145.png` muestra el componente con etiquetas de ejemplo "Patio"/"Clima" que no corresponden a las etiquetas reales de la app ("Inicio", "Registrar", "Historial"). Para verificar la paridad real del tab bar, la referencia correcta es el tab bar embebido en los frames de pantalla completa (`home/home1-530-7951.png`, `app-shell/screen-07-tab-bar-home-active.png`), donde sí coincide: fondo teal, 3 ítems, pill claro sobre el ítem activo con ícono + texto en color oscuro, resto de ítems en blanco/translúcido.
