# Registro consolidado de riesgos — Migración UVA App (Ionic → React Native)

Riesgos fusionados y **deduplicados** a partir de los 10 documentos de descubrimiento. Varios temas (Chart.js, generación del reporte, theming CSS-var, DataStore, lifecycle de Ionic) fueron reportados por múltiples agentes; aquí aparecen como **un único riesgo consolidado** citando todos los docs fuente.

**Severidad**: `critical` = bloquea el arranque/función core o sin equivalente directo · `high` = reescritura sustancial o alto riesgo de regresión · `medium` = mapeo no trivial con riesgo acotado · `low` = limpieza o impacto menor.

**Fases del plan** referenciadas en la columna "Fase":
- **F0 — Setup/Infra**: proyecto Expo, EAS, credenciales, Amplify bootstrap, navegación base.
- **F1 — Datos & Lógica**: portar Amplify/DataStore, lógica pura, gamificación, fase lunar, tests.
- **F2 — Navegación & Estado**: React Navigation, stores/contexts, lifecycle, guards.
- **F3 — UI & Componentes**: pantallas, componentes, modales, theming, iconos, fuentes.
- **F4 — Capacidades nativas**: notificaciones, filesystem, share, back/minimizar, permisos.
- **F5 — Reporte & Gráficas**: gráfica de área y generación de imagen del reporte.
- **F6 — Hardening/Release**: limpieza, validación en dispositivo, pipeline de release.
